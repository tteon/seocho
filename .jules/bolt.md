Performance optimization implemented: Replaced `read_text().splitlines()` with lazy file iteration `with path.open('r', encoding='utf-8') as f:` in various benchmark/eval scripts (`inference_workbench.py`, `smoke_plugin.py`, `h0_gate.py`, `results_log.py`, `e2e_axiom_ab.py`, `e2e_cold_start_ab.py`, `e2e_cross_model_intern.py`, `e2e_ontology_source_ab.py`). Also applied similar changes to `test_env_contract.py` and `test_serving_image_hardening.py` to prevent reading entire large log/jsonl/env files into memory at once, reducing avoidable file I/O and JSONL overhead. Explicit `.rstrip('\n')` was used where necessary to preserve exact string processing behavior, while implicit `strip()` in `json.loads` parsing was relied upon for JSONL lines. Tests in `extraction/tests/test_tools.py` fail with `AttributeError: 'RunContextWrapper' object has no attribute 'run_config'` due to an out-of-scope repository issue that can be safely ignored per memory guidelines since our modifications are strictly limited to pure utility `scripts/` and tests.
