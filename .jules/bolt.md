Performance finding: Avoid using `.read_text().splitlines()` for reading files, as it loads the entire file into memory and creates a large list of strings. This can cause high memory usage and slowdowns, especially for large JSONL or log files. Instead, use lazy file iteration with `with open(path, "r", encoding="utf-8") as f: for line in f:`. This approach is much more memory-efficient and performs better for large inputs.
