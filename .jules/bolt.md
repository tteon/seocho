- Changing `read_text().splitlines()` to lazy iteration `with open(...) as f:` is a relevant performance improvement when processing JSONL or large text logs, as it avoids loading the entire file into memory at once. (Memory rule: Always stream `.jsonl` and `.env` files (e.g., in `eval/`, `index/`, or `scripts/` modules) using `with path.open('r', encoding='utf-8') as f:` for lazy iteration rather than `read_text().splitlines()`)
