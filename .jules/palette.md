In the SEOCHO repository, CLI empty state and error messages (e.g., printed strings in src/seocho/cli/) should use proper sentence case and punctuation, typically following the format 'No <domain item> found.' (e.g., 'No graph targets found.', 'No matching trace spans found.'). Be careful to respect domain terminology to avoid contextual errors (e.g., use 'No search results found.' for search commands, and 'No quarantined items found.' for ontology quarantines, instead of applying generic terms like 'No memories found.' incorrectly).
