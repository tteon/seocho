refactor: improve file reading performance

Replaced instances of `path.read_text().splitlines()` with lazy file iteration `with path.open("r", encoding="utf-8") as f: for line in f:` in several benchmark, evaluation, and test scripts. This prevents loading entire files into memory at once as a single large list of strings, which is especially important for JSONL traces and evaluation logs.
