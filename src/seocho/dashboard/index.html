    A clearer experiment loop.

    Start small. Preserve the result. Change one thing.

    01

    Capture a baseline

    Use your documents, ontology and stable question IDs. Prepare a separate empty graph target for each full E2E run. 

    seocho run seocho.run.yaml --dry-run
seocho run seocho.run.yaml --no-track

    Running these CLI commands may call your configured model and database. This dashboard only reads saved results.

    02

    Find the failure

    Open an experiment and inspect its questions, graph evidence, missing slots and diagnostics. A completed run is not a quality grade. 

    seocho runs dashboard ./runs

    After a run finishes or saves a checkpoint, use Refresh runs to load it here.

    03

    Compare the change

    Select a baseline and candidate. Declare changed conditions and a hypothesis. The comparison checks the recorded input fingerprints.

    Missing or incompatible evidence prevents aggregate deltas. You can still inspect individual answers and failures.

    Recorded evidence comes first.

    This workspace displays run receipts and recorded phase durations. It does not infer trace spans, token costs, backend compatibility or causal quality improvements. Request-level costs remain in the separate inference cost workbench.
